Projects

Mail Extractor

Built an asynchronous Python email crawler for extracting email addresses from websites. Implemented asyncio and aiohttp for concurrent network requests using a shared queue with 5 workers.

Added same-domain filtering to avoid unnecessary external crawling and used sets to prevent duplicate URLs from being processed. Implemented regex-based email extraction with false-positive cleaning and validation.

The asynchronous implementation achieved approximately 3x faster execution compared to the synchronous version.

Tech Used: Python, FastAPI, asyncio, aiohttp
